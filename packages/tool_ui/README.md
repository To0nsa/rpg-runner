# Tool UI

Shared Flutter theme, tokens, panel/section/workspace/list cards, visual catalogs
and responsive three-panel layout for the content editor and Admin app.
Import `package:tool_ui/tool_ui.dart`. Widgets own presentation; callers retain
selection, persistence and domain actions. See
[architecture](../../docs/tdd/admin_tools.md) and
[panel/scroll contracts](../../docs/tdd/editor_ui_system.md).
