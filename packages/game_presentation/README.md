# Game presentation

Shared Core-backed gear, ability and projectile names/icons for the game and
Admin. Import individual public files such as `game_icon.dart`, `gear_text.dart`
or `catalog_item.dart`. `CatalogGift` describes an attachment for display; the
backend owns validation and grants. Consumers supply the canonical game artwork
through their asset bundle. No filesystem, Firebase or application dependency.
See [architecture](../../docs/tdd/admin_tools.md).
