# Willow local verification — November 7, 2026

Scope: the complete playable bounty hunter, named Willow, with 25 abilities,
three pre-run weapons, unlimited cooldown bombs, independent builds and character
selection. Missing item/ability illustrations remain empty. Source is asset
import `b6e0cf26` plus the implementation committed with this report.
Checks ran locally on Windows with Dart 3.13.1; none establish cloud or device
deployment. See [gameplay](../gdd/combat/abilities/willow.md) and the
[technical contract](../tdd/willow.md).

with `2026.11.7`. The existing offline helper,
`node functions/tool/refresh_navigation_routes.mjs`, regenerated it from the
production seed algorithm. Rebuilding and rerunning the affected tests passed;
no emulator-dependent behavior changed in that repair. A targeted invocation
initially ran from the wrong directory and failed a relative file read; the
Functions-directory invocation above passes. Emulator lock-timeout warnings
caused no other failed assertions.

all gun/shot combinations and pellet budgets, bomb terrain and wall occlusion,
no friendly fire, one blast only, bomb statuses, empty-resource use, owner

## Compiled replay benchmark

The Windows validator, compiled from `bin/server.dart` to
`.tmp/bounty_replay_validator.exe`, ran `benchmark --ticks=36000 --strict`:
36,000 ticks per level, 60 Hz, seed 4401, generated terrain with combat objectives
disabled. Source was `b6e0cf26` plus the implementation. Subsequent UI/docs/tests,
formatting and Willow lunge-art edits do not change this benchmark's
terrain/default-character inputs.

## Limits

No deployment, remote deletion, board mutation, ticket cancellation, device
installation or signed Android acceptance was performed. The game is not live;
fresh profiles include Willow without a new old-profile migration or older-client
fallback. Version checks still reject mismatched simulations. Existing
development accounts can be reset when installing the new version.

Fieldcraft uses a ready pose because the supplied pack has no dedicated cast
animation. No dedicated quarry marker artwork was added. Balance values need
human playtesting. Unused wall-slide, ledge, ladder and crouch source animations
do not introduce extra traversal mechanics beyond the agreed roster.
