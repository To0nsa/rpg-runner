# Archived Building Plans

This folder holds closed implementation plans and completed phase checklists.

Archived docs are historical context. They may describe completed work, shipped
contracts, or superseded implementation paths. New work should usually start
from the active docs in `docs/building/` unless an archived plan is explicitly
being used as background.

Archive policy:

- move plans here only when their own status says the implementation plan is
  complete, implemented, historical, or otherwise closed
- keep partially implemented or pending plans in the active tree
- preserve the original path under `docs/building/archived/`
- for completed implementation records that originated outside `docs/building/`,
  use a clearly named topical folder and state the original location in the
  archived document
- update active links after moving files
