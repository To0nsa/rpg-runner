# Achievements - design in progress

The current proposal is [Hall of Honour - achievements](../building/achievements.md).
It records the agreed Town destination, expandable achievement rows, completion
dates and direct gold claims, alongside provisional tuning and open questions.
Achievements are not implemented; the design is still being developed.

The [earlier 24-achievement proposal](../archive/2026-10-30/gdd/12_achievements.md)
is preserved as an idea backlog. It does not define the current first release.
